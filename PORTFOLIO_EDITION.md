# Portfolio Edition

## English

The current default-branch tree contains project presentations only. Source files, build inputs, executable assets, configuration templates and implementation documentation have been removed from this version.

This change does not erase previous commits, other branches, tags, releases, downloaded copies or external forks. Restricting access to the original history requires additional repository administration. Do not interpret this documentation-only tree as proof that previously published code is inaccessible.

## Português (Brasil)

A árvore atual da branch principal contém somente apresentações do projeto. Arquivos de código, insumos de build, recursos executáveis, modelos de configuração e documentação de implementação foram retirados desta versão.

A alteração não apaga commits anteriores, outras branches, tags, releases, cópias baixadas ou forks externos. Restringir o acesso ao histórico original requer administração adicional do repositório. A ausência de código na versão atual não significa que o código publicado anteriormente esteja inacessível.
